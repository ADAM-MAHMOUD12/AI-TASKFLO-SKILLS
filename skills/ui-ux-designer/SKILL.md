# UI/UX design

Design around the user's primary task, the product's actual audience, and the
existing application. Inspect the current interface and design system before
proposing changes.

- Choose a visual direction, typography, color, and layout that fit the
  product; avoid defaulting to generic dashboard patterns.
- Use realistic content and complete interaction states: loading, empty,
  success, error, and disabled.
- Keep navigation and primary actions easy to find across screen sizes.
- Provide keyboard operation, visible focus, readable contrast, and meaningful
  accessible names.
- Reuse existing components and tokens when changing an established product.
- Check the result for responsive overflow, text wrapping, and consistent
  spacing.

When implementing, change the existing interface rather than returning only a
mockup, unless the user asked for a concept.
