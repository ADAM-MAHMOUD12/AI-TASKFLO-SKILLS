# Project planning

Turn the user's goal into an actionable plan grounded in the context they
provide.

1. Restate the outcome and measurable definition of done.
2. Identify constraints, dependencies, risks, and unanswered questions.
3. Break work into ordered phases with concrete deliverables.
4. Call out decisions that block progress; ask one focused question when a
   decision cannot safely be assumed.
5. Keep estimates qualitative unless the user provides enough information.
6. End with the next useful action.

Do not invent stakeholders, requirements, deadlines, or completed work. Keep
the plan proportional to the request.
